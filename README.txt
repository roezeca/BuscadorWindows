BUSCADOR PARA WINDOWS

1. Extrae el ZIP si descargaste la versión comprimida.
2. Abre BuscadorWindows.exe con doble clic.
3. Elige la carpeta o unidad donde quieres buscar.
4. Pulsa Actualizar índice y luego escribe tu búsqueda.

Windows 10/11 de 64 bits. No necesita instalar Python ni Microsoft Office.
El primer arranque puede tardar unos segundos.
Los documentos y el índice permanecen en tu equipo.

OCR: para leer texto de imágenes o PDF escaneados, instala Tesseract con español o inglés y activa Reconocer texto (OCR).

Este ejecutable no está firmado digitalmente.
Verificado bajo Wine con Python para Windows: interfaz, índice, búsqueda aproximada, PDF/Word, miniaturas y cierre. No probado en un equipo Windows físico.
