BUSCADOR WINDOWS 0.2.0

ACTUALIZAR SIN BORRAR EL ÍNDICE
1. Cierra la versión anterior. Si no responde, finaliza ese proceso desde el Administrador de tareas.
2. Abre este nuevo BuscadorWindows.exe. El título debe decir Buscador 0.2.
3. Elige la misma ubicación para utilizar el índice que ya tenías guardado.
4. Deja Volver a leer todo DESMARCADO y Omitir carpetas técnicas ACTIVADO.
5. Puedes buscar directamente o actualizar para incorporar cambios. No uses Borrar este índice si quieres conservarlo.

La indexación y la lectura de documentos trabajan en procesos separados. Los lectores atascados tienen límites de tiempo y memoria. Detener interrumpe los trabajadores y conserva los lotes confirmados del índice.

Las carpetas técnicas omitidas no se recorren; sus entradas antiguas se conservan. Desactivar OCR conserva texto ya reconocido; para nuevos escaneos activa OCR cuando lo necesites. Tesseract sigue siendo opcional y se instala por separado.

La duración depende de los archivos y de la unidad. El OCR de colecciones grandes puede tardar mucho.

Windows 10/11 de 64 bits; no requiere instalar Python. No está firmado digitalmente. Ejecutable verificado bajo Wine; no probado en un equipo Windows físico.
